# Опросники — Павел Фадеев

Страницы-опросники для клиентов. Клиент открывает ссылку с телефона, заполняет, результат приходит мне в Telegram с уже подсчитанными баллами и расшифровкой. Свои баллы клиент не видит — расшифровку даю я на встрече.

## Что здесь лежит

| Ссылка для клиента | Что это | Время |
|---|---|---|
| https://fadpv.github.io/oprosniki/ | **PHQ-9 и GAD-7.** Настроение и тревога за последние две недели. Базовый набор для первой встречи. Файл: `index.html` | ~3 мин |
| https://fadpv.github.io/oprosniki/fesi.html | **FES-I.** Уверенность при ходьбе — насколько человек беспокоится, что упадёт, в 16 бытовых ситуациях. Плюс «мешает жизни 0–10» и число падений за месяц. Для страха падения, головокружений, проблем с равновесием. Файл: `fesi.html` | ~4 мин |

## Как узнать ссылку на любой файл

Адрес всегда собирается одинаково:

`https://fadpv.github.io/oprosniki/` + имя файла

Единственное исключение — `index.html`: он открывается по короткому адресу без имени файла, потому что `index` для сайта означает «главная страница».

Список всех файлов — на главной странице репозитория, выше этого текста. Проверить, что сайт вообще опубликован, и увидеть его адрес: вкладка **Settings** → слева **Pages**, там строка «Your site is live at …».

## Как добавить новый опросник

1. На главной странице репозитория: **Add file** → **Create new file**.
2. В поле имени написать имя латиницей, без пробелов, с `.html` на конце. Например `audit.html`.
3. Вставить готовый код страницы в большое поле.
4. Внизу **Commit changes** → ещё раз **Commit changes**.
5. Через минуту-две страница доступна по адресу `https://fadpv.github.io/oprosniki/имя-файла.html`.
6. Дописать строку в таблицу выше, чтобы через месяц не гадать, что это за файл.

## Как переименовать файл

Открыть файл в репозитории → карандаш (**Edit this file**) → наверху в поле с именем файла стереть старое имя и написать новое → **Commit changes**.

**Осторожно:** после переименования старая ссылка перестаёт работать. Если ссылку уже кто-то из клиентов получил — он попадёт на «Page not found». Переименовывать имеет смысл только тогда, когда ни у кого нет незаполненной ссылки на этот файл.

Отдельно про `index.html`: если переименовать его, короткий адрес `https://fadpv.github.io/oprosniki/` перестанет открываться. Лучше не трогать.

## Как это устроено внутри

Каждая страница — один самостоятельный HTML-файл. Внизу кода, в блоке `НАСТРОЙКА`, две строки: `TOKEN` — токен телеграм-бота, `CHAT_ID` — номер моего чата. Больше ничего настраивать не нужно, сервер не требуется.

## Рабочие правила

- Ссылку отправлять лично клиенту, который сказал «да, продолжаю» — вместе с информированным согласием, в тот же день.
- Результаты смотреть в день получения. Если в сообщении есть строка с ⚠️ (пункт 9 PHQ-9 — мысли о смерти или самоповреждении), это повод связаться с клиентом сегодня, а не ждать сессии.
- Баллы читать по пунктам, а не только по сумме: сон, энергия и концентрация бывают высокими из-за соматики, а не депрессии.
- Если ссылка куда-то утекла и в чат пошёл мусор — в BotFather команда `/revoke`, новый токен вписать во все файлы и перезалить.

## Оговорка про FES-I

Шкала валидирована на пожилых людях, и пороги (16–19 низкая обеспокоенность, 20–27 умеренная, 28–64 высокая) выведены на них. Для клиентов среднего возраста надёжнее смотреть не на категорию, а на динамику балла от встречи к встрече. Русские формулировки пунктов — рабочий перевод с официальной английской версии.
